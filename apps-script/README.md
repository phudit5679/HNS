# ตั้งค่าที่เก็บรูปบน Google Drive

ใช้ฟรี ไม่ต้องผูกบัตร รูปหลักฐานจะไปอยู่ใน Google Drive ของบัญชีที่ตั้งค่า
ส่วน Firebase จะเก็บแค่คะแนนและลายเซ็น ทำให้พื้นที่ฟรี 1 GB ใช้ได้หลายปี

ทำครั้งเดียว ใช้เวลาประมาณ 10 นาที

โครงสร้างโฟลเดอร์ที่ได้:

```
โฟลเดอร์หลัก/
 └─ 2569-10 ต.ค./
     └─ S001 สาขาบางนา 15-10-2569/
         ├─ 1.13.jpg
         └─ 2.1.jpg
```

ระบบจำ ID ของโฟลเดอร์ไว้ใน Firebase จึงย้ายหรือแก้ชื่อโฟลเดอร์เองได้โดยไม่กระทบการเปิดดูรูป
(ถ้าแก้ไขผลการตรวจแล้วบันทึกใหม่ ระบบจะตั้งชื่อและย้ายโฟลเดอร์กลับตามรูปแบบนี้)

## 1. สร้างโฟลเดอร์เก็บรูป

1. เปิด https://drive.google.com ด้วยบัญชีที่จะใช้เก็บรูป (แนะนำบัญชีบริษัท)
2. สร้างโฟลเดอร์ใหม่ เช่น `Cafe Audit Images`
3. เปิดโฟลเดอร์นั้น แล้วคัดลอก ID จากลิงก์ด้านบน
   ลิงก์จะหน้าตาแบบ `https://drive.google.com/drive/folders/1AbCdEfGh...`
   ส่วน `1AbCdEfGh...` หลัง `folders/` คือ ID

**ไม่ต้องแชร์โฟลเดอร์ให้ใคร** สคริปต์จะเป็นตัวอ่านและเขียนรูปให้

## 2. สร้าง Apps Script

1. เปิด https://script.google.com แล้วกด **New project** (โครงการใหม่)
2. ตั้งชื่อโปรเจกต์ เช่น `Cafe Audit Images`
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ทั้งหมด แล้ววางโค้ดจากไฟล์ `apps-script/Code.gs` ใน repo นี้
4. แก้ 2 บรรทัดบนสุด
   - `FOLDER_ID` = ID โฟลเดอร์จากขั้นตอนที่ 1
   - `TOKEN` = ตั้งรหัสลับเอง เช่น `hns-audit-8f3k2p9x` (ยาวๆ เดาไม่ได้)
5. กด 💾 บันทึก

## 3. เผยแพร่เป็น Web app

1. กด **Deploy → New deployment** (การทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่)
2. กดรูปเฟือง ⚙️ ข้าง Select type แล้วเลือก **Web app**
3. ตั้งค่า
   - **Execute as:** Me (ตัวคุณ)
   - **Who has access:** Anyone (ทุกคน)
4. กด **Deploy**
5. Google จะขอสิทธิ์เข้าถึง Drive ให้กด **Authorize access** แล้วเลือกบัญชี
   - ถ้าขึ้น "Google hasn't verified this app" ให้กด **Advanced → Go to ... (unsafe)** เพราะเป็นสคริปต์ของคุณเอง
6. คัดลอก **Web app URL** (ขึ้นต้นด้วย `https://script.google.com/macros/s/...` และลงท้ายด้วย `/exec`)

## 4. ใส่ค่าในเว็บ

ส่ง **Web app URL** และ **TOKEN** ให้ผู้ดูแลระบบใส่ใน `index.html` สองบรรทัดนี้

```js
const IMAGE_SCRIPT_URL = '';
const IMAGE_SCRIPT_TOKEN = '';
```

ถ้าเว้นว่างไว้ ระบบจะเก็บรูปใน Firebase แบบเดิม

## ถ้าแก้โค้ดใน Code.gs ภายหลัง (รวมถึงตอนวางโค้ดรุ่นใหม่)

ถ้าวางโค้ดใหม่ทับทั้งไฟล์ อย่าลืมใส่ `FOLDER_ID` และ `TOKEN` เดิมกลับเข้าไป แล้วกด **Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy**
ไม่อย่างนั้นเว็บจะยังใช้โค้ดเก่า (ลิงก์เดิมใช้ต่อได้)

## ข้อจำกัด

- พื้นที่ใช้ร่วมกับ Google Drive ของบัญชีนั้น (บัญชีฟรี 15 GB) รูปละประมาณ 40–80 KB
  ถ้าบันทึก 400 รายการต่อเดือน รายการละ 6–15 รูป จะใช้ประมาณ 100–500 MB ต่อเดือน
- รูปที่ถูกแทนที่หรือลบจะอยู่ในถังขยะ 30 วันก่อนหายไปเอง (ระหว่างนั้นยังนับพื้นที่)
- TOKEN อยู่ในโค้ดหน้าเว็บ คนที่เปิดดูโค้ดหน้าเว็บจะเห็นได้ (ระดับความปลอดภัยเดียวกับ Firebase ที่ใช้อยู่)
